💡 Why Self-Hosted IR?

SAP is on-premise, so you need Self-Hosted IR installed on a Windows VM that can access SAP. Azure IR is used for Azure-to-Azure tasks (like Data Lake to Databricks).

💡 How Triggers Work:
  1. You create a trigger with a schedule (e.g., "Daily at 2 AM")
  2. You associate the trigger with one or more pipelines
  3. ADF automatically runs those pipelines at the scheduled time
  4. You monitor the runs in the "Pipeline Runs" section
