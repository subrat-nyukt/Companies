📝 ETL Notebook: Bronze → Silver → Gold

Run Spark transformations to clean and aggregate data.

# Read from Bronze (Data Lake) df_customers = spark.read.csv("/mnt/bronze/KNA1_*.csv", header=True) df_sales = spark.read.csv("/mnt/bronze/VBAK_*.csv", header=True) # Clean to Silver df_clean = df_customers.dropna().dropDuplicates() # Aggregate to Gold df_gold = df_sales.groupBy("LAND1").sum("NETWR") # Save as Delta Table df_gold.write.format("delta").save("/mnt/gold/sales_summary")
