1
Create Service Principal

Azure Portal:

Azure Active Directory → App registrations → + New registration

Name: databricks-datalake-sp
Type: Single tenant
Save these values:
• Application (client) ID
• Directory (tenant) ID
2
Create Client Secret

In your App Registration:

Certificates & secrets → + New client secret

⚠️ Copy the secret VALUE immediately! It won't be shown again!
Example secret:
AbC123_~xYz789-pQr456
3
Grant Permissions to Data Lake

Storage Account:

adlspostpaydev → Access Control (IAM) → + Add role assignment

Role: Storage Blob Data Contributor
Assign to: databricks-datalake-sp
✅ This gives read/write access to your service principal
4
Store Secrets in Databricks

Create Secret Scope:

# Create scope databricks secrets create-scope \ --scope data-lake-scope # Add secrets databricks secrets put \ --scope data-lake-scope \ --key client-id databricks secrets put \ --scope data-lake-scope \ --key tenant-id databricks secrets put \ --scope data-lake-scope \ --key client-secret
5
Configure Spark Connection
# Get secrets securely client_id = dbutils.secrets.get( scope="data-lake-scope", key="client-id" ) tenant_id = dbutils.secrets.get( scope="data-lake-scope", key="tenant-id" ) client_secret = dbutils.secrets.get( scope="data-lake-scope", key="client-secret" )
6
Read/Write Data
# Read from Bronze df = spark.read.parquet( "abfss://bronze@adlspostpaydev.dfs.core.windows.net/sap/kna1/" ) # Transform df_clean = df.dropna().dropDuplicates() # Write to Silver df_clean.write.mode("overwrite").parquet( "abfss://silver@adlspostpaydev.dfs.core.windows.net/customers/" )

[ 1 ] Configure Connection
# Get credentials from secret scope client_id = dbutils.secrets.get(scope="data-lake-scope", key="client-id") tenant_id = dbutils.secrets.get(scope="data-lake-scope", key="tenant-id") client_secret = dbutils.secrets.get(scope="data-lake-scope", key="client-secret") # Configure Spark spark.conf.set("fs.azure.account.auth.type.adlspostpaydev.dfs.core.windows.net", "OAuth") spark.conf.set("fs.azure.account.oauth.provider.type.adlspostpaydev.dfs.core.windows.net", "org.apache.hadoop.fs.azurebfs.oauth2.ClientCredsTokenProvider") spark.conf.set("fs.azure.account.oauth2.client.id.adlspostpaydev.dfs.core.windows.net", client_id) spark.conf.set("fs.azure.account.oauth2.client.secret.adlspostpaydev.dfs.core.windows.net", client_secret) spark.conf.set("fs.azure.account.oauth2.client.endpoint.adlspostpaydev.dfs.core[.windows.net", f"https://login.microsoftonline.com/{tenant_id}/oauth2/token") print("✅ Connected to Data Lake!")
